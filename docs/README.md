# docs

This directory contains the MkDocs documentation source for the `tcr-seek` GitHub Pages site. The site follows the same broad structure as `cell-seek`: an overview page, command-focused usage pages, method notes, FAQ, and license page.

Build the site from the `tcr-seek` directory with `mkdocs build`. Serve it locally with `mkdocs serve` when the MkDocs dependencies are available.
